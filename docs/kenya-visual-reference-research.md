# Kenya-Grounded Visual Reference Research for SURA

SURA’s visual work should use research as an **inspiration framework**, not a source of copied package artwork, company marks, product claims, or cultural shorthand. The implementation will use original swatches and clearly labelled SURA illustrative packaging studies rather than representing them as genuine company inventory.

| Source | Key finding | SURA application |
| --- | --- | --- |
| [BuyRentKenya: *Incorporating Cultural Elements into Design*](https://www.buyrentkenya.com/discover/incorporating-cultural-elements-into-design) | Kenyan interior references include kanga colour, Maasai shuka red/blue, wood, sisal, stone, earthy savanna tones, Swahili architectural detail, and contemporary/traditional blending. | Material-led palette language: terracotta, sisal, stone, coastal teal, and natural wood. Avoid treating cultural markers as costume. |
| [Figma: *100 color combinations*](https://www.figma.com/resource-library/color-combinations/) | Colour harmony can support hierarchy, brand recognition, emotional tone, and accessibility; useful structures include monochromatic, analogous, complementary, triadic, tetradic, and split-complementary systems. | Retain high-contrast core text; use expressive colour as controlled accents and visual swatches. |
| [Tetra Pak Kenya: *Packaging design trends*](https://www.tetrapak.com/en-ke/insights/food-categories/dairy/packaging-design-trends) | Packaging can function as a brand canvas. Its “Full Spectrum” discussion uses energetic contrast, electric blue, bright pink, vivid green, deep red, and softened pastel edges to signal fun and optimism. | Use a restrained high-energy direction for SURA’s Thermal Bloom and Tangerine Social visual studies, keeping UI text neutral and readable. |
| [Interior Design Society of Kenya: *Kenyan colour palette*](https://idsk.or.ke/tag/kenyan-colour-palette/) | The society frames current Kenyan interiors around personal expression, cultural heritage, environmental respect, and globally informed local design. | Let members combine a contemporary palette with material-minded type and imagery choices; avoid reducing Kenyan design to a single visual language. |

## Original SURA visual directions

The refined system will pair each member-facing palette with a type temperament and a non-product “material study”: paper grain, woven line, soft gradient, stone field, or ink wash. These study images will be labelled as **SURA visual studies**, never presented as connected-company stock, package photography, or customer work.

> A third-party Kenya beverage-brand case study was located but blocked by an access-verification page. It is not relied upon for implementation, and no protected imagery or brand artwork will be reused.
